Data — 10 tools & ways to use them

Capture, analyze, and visualize data effectively.

  1. SQL (Postgres) — Structured queries and analytical reports; use views for common logic.
  2. Python (pandas) — Data cleaning and ETL for reproducible workflows.
  3. Jupyter Notebooks — Exploratory analysis and shareable reports with code + narrative.
  4. Airflow / Prefect — Orchestrate ETL pipelines and scheduled jobs reliably.
  5. Looker / Metabase — Business-facing dashboards and self-serve analytics.
  6. BigQuery / Redshift — Scalable data warehouses for analytics at scale.
  7. Data validation (Great Expectations) — Assert data quality as part of pipelines.
  8. Visualization (D3, Vega) — Custom visualizations for interactive insights.
  9. ML frameworks (scikit-learn, TensorFlow) — Prototype models and evaluate performance.
  10. Instrumentation — Log and metric strategy to measure product impact and experiments.
